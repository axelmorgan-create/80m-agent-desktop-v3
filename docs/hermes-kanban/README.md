# Hermes Kanban Reference Pack

Source: `NousResearch/hermes-agent` main at commit `50ab0a85a7472017a26abd7794103ddffed3d450`.

Files in this folder are the downloaded reference materials attached to the desktop app's Kanban screen:

- `kanban.md` - official Kanban overview.
- `kanban-tutorial.md` - official workflow tutorial.
- `devops-kanban-worker.md` - worker skill reference.
- `devops-kanban-orchestrator.md` - orchestrator skill reference.
- `HERMES_AGENT_V0.12.0_RELEASE_NOTES.md` - v0.12 release notes snapshot.
- `hermes-kanban-v1-spec.pdf` - upstream Kanban design spec.
